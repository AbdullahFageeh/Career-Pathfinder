# Psychometric-first job selection

## Decision order

The job desk now uses **psychometric-first** scoring when `selectionProfile` is set to `psychometric-first` in the private automation configuration. This mode is deliberately based on explicit posting text only. It does not infer an employer's culture, work-life balance, psychological safety, or autonomy when a listing does not state them.

| Weight | Layer | What it represents |
| ---: | --- | --- |
| 55% | Psychometric alignment | Structured project delivery, systems and root-cause work, empathetic leadership, live hands-on implementation, and expert autonomy. |
| 35% | Career evidence fit | Existing title, experience, seniority, location, channel, and freshness evidence. |
| 10% | Ikigai alignment | Human-centric operations, diagnosis-led advisory work, teaching/development, and live mission-driven delivery. |

The **psychometric report is primary**. The Ikigai report is secondary and is used only for the practical career-direction themes that repeat the measured profile; symbolic or astrological material is not used for ranking.

A **career-domain gate** runs before queueing. This prevents generic wording such as “operations,” “planning,” or “process improvement” from promoting an unrelated finance, accounting, software engineering, cybersecurity, sales-first, or front-of-house service specialty. A role must also contain explicit evidence of event, venue, production, site, installation, logistics, project implementation, or human-systems/workforce-development scope.

## Strong signals

The queue favors explicit role text about structured project delivery, implementation, operational systems, workflow or process improvement, diagnosis, stakeholder coaching, team development, mentoring, site operations, venues, events, sports, installations, consulting, advisory work, or solution design.

## Hold signals

The queue holds roles explicitly centred on cold calling, sales quotas, commission targets, competitive negotiation, high-volume call centres, data entry, or repetitive administrative processing. It does not reject a role because an employer's culture is unknown; it marks culture as a human-review question instead.

## Career direction

The filter is designed to prioritize the near-term bridge identified in Abdullah's reports: **structured, high-intensity, site-based technical or operations project delivery with systems-improvement and people-development scope**. It gives secondary preference to roles that create a path toward human-centric operations, organizational workflow consulting, sports-tech, or mental-health-tech.

## Human review remains required

No score can verify the team, leadership style, workload, project rhythm, recovery expectations, or psychological safety. For every high-scoring role, the reviewer should check whether the role offers clear outcomes, bounded projects or phases, meaningful systems ownership, and enough autonomy to design the work.
